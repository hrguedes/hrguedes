## Resume

I'm a software engineer with 9+ years of experience building and scaling systems that need to handle **high demand and large volumes of data**. I like working across the whole lifecycle: designing the architecture, writing the code, shipping it and keeping it healthy in production.

I've spent a good part of my career modernizing legacy systems and designing new ones with microservices, and lately I've been bringing **AI** into the mix: integrating it into real architectures and using it to automate work that used to be manual.

- **Legacy modernization:** refactoring and migrating to modern platforms
- **AI engineering:** see below
- **Quality:** TDD, code review, automated pipelines
